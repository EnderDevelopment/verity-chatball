# Minecraft plugin: Verity, la Bola Amiga

Verity es un plugin de Minecraft para Paper que añade un compañero representado por un bloque de terracota vidriada amarilla. Los jugadores nuevos reciben una caja de Verity, pueden abrirla para obtenerla, colocarla en el mundo, hablarle escribiendo su nombre en el chat y recogerla de nuevo para guardarla en el inventario.

## Install

1. Descarga el archivo JAR del plugin.
2. Usa un servidor Paper compatible con Minecraft 1.21.11.
3. Asegúrate de que el servidor utilice Java 21.
4. Detén el servidor antes de instalar el plugin.
5. Copia el archivo JAR en la carpeta `plugins`.
6. Inicia o reinicia el servidor.
7. Comprueba que Verity se haya cargado correctamente en la consola.

El plugin crea y utiliza su propia configuración para conservar las ubicaciones de las Verity colocadas cuando el servidor se apaga.

## Use

1. Entra al mundo por primera vez. Recibirás una caja de Verity en el inventario.
2. Haz clic derecho con la caja para abrirla y obtener el objeto Verity.
3. Coloca Verity como un bloque de terracota vidriada amarilla.
4. Escribe “Verity” en el chat mientras estés a un máximo de 10 bloques de una Verity colocada.
5. Verity responderá con una de varias respuestas preprogramadas.
6. Rompe el bloque de Verity para recoger nuevamente el objeto y guardarlo en el inventario.

La entrega inicial de la caja se realiza solamente a jugadores que nunca habían entrado antes al servidor. El plugin no incluye comandos ni permisos personalizados.
